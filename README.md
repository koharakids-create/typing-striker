# ⚽ タイピングストライカー

サッカー × タイピングの、小学生向けブラウザゲームです。
ことばを打つたびにドリブルで前進し、2語ごとにディフェンスを1人抜き、最後の「シュートワード」を打ち切るとゴール！

- **ひとりで リーグせん**：地域リーグ → 県リーグ → 関東リーグ → JFL → J3 → J2 → J1 → ヨーロッパリーグ（全8ステージ）
- **みんなで たいせん**：2〜4人がそれぞれのパソコンから、4けたの部屋番号で同じ試合に参加
- **れんしゅう**：5つのレベルから選んで、相手なしで練習
- サッカーの用語・ルール・用具・ポジション・大会/チーム・選手名を **約440語** 収録（ランダム出題）

GitHub に置いて、Cloudflare Workers（無料プランで可）で公開します。サーバー代・音声ファイル・画像ファイルは不要です。

---

## 遊び方（子ども向け説明はゲーム内「あそびかた」にもあります）

1. 日本語入力をオフ（「半角/全角」キー）。オンのままだと画面に注意が出ます。
2. 表示されたことばをローマ字で入力。下にお手本が出ます（`shi`/`si`、`tsu`/`tu`、`ja`/`zya` など、どのつづりでもOK）。
3. ん＝`nn`、っ＝次の子音を2回（`kka`）、ー＝マイナスキー。

## ゲームのルール（数値）

| 項目 | 値 |
|---|---|
| 1試合の語数 | ディフェンス人数 × 2 ＋ 1（最後の1語がシュート） |
| ディフェンスを抜くタイミング | 2語打ち終わるごとに1人 |
| ミスしたとき | 選手がよろけるだけ（後退なし・やさしい設計） |
| オンライン対戦の締め切り | 1人目がゴールしてから30秒 |
| 1部屋の最大人数 | 4人（2人からスタート可） |

### レベル（よみの文字数で自動判定）

| レベル | よみの文字数 | 例 |
|---|---|---|
| 超初心者 | 〜3 | パス、ゴール、メッシ |
| 初心者 | 4〜5 | シュート、オフサイド |
| 中級 | 6〜7 | コーナーキック、三笘薫 |
| 上級 | 8〜10 | ペナルティエリア |
| プロ級 | 11〜 | ビデオアシスタントレフェリー |

### リーグ設定（`public/app.js` の `LEAGUES`）

| ステージ | レベル | DF人数 | 相手の速さ（かな/秒） |
|---|---|---|---|
| 地域リーグ | 超初心者 | 2 | 0.8 |
| 県リーグ | 超初心者・初心者 | 2 | 1.1 |
| 関東リーグ | 初心者 | 3 | 1.4 |
| JFL | 初心者・中級 | 3 | 1.8 |
| J3 | 中級 | 4 | 2.2 |
| J2 | 中級・上級 | 4 | 2.7 |
| J1 | 上級 | 5 | 3.2 |
| ヨーロッパリーグ | 上級・プロ級 | 5 | 3.9 |

相手チーム（CPU）より先にゴールすれば勝ち、次のリーグが解放されます。進み具合はブラウザに保存されます。
難しすぎる・簡単すぎるときは `cpu` の数値を **0.1〜0.3 ずつ** 変えて調整してください。

## ことばを増やす・変える

`public/words.js` の `WORD_SOURCE` に1行ずつ追加するだけです。

```
# 選手（日本）           ← 「# 」で始まる行がカテゴリ名
三笘薫|みとまかおる      ← 表示|よみ（ひらがな・カタカナ・ー のみ）
```

レベルはよみの文字数から自動で決まります。

## 公開手順（GitHub ＋ Cloudflare）

### 1. GitHub にアップロード
1. GitHub で新しいリポジトリ（例：`typing-striker`）を作成
2. このフォルダの中身をすべてアップロード（`node_modules` は不要）

### 2. Cloudflare につなぐ（おすすめ：Workers Builds）
1. Cloudflare ダッシュボード →「Workers & Pages」→「作成」→「リポジトリをインポート」（Import a repository）
2. GitHub と連携して `typing-striker` を選ぶ
3. ビルド設定はそのまま（デプロイコマンド `npx wrangler deploy`）で「デプロイ」
4. `https://typing-striker.<あなたのサブドメイン>.workers.dev` で遊べます

以後、GitHub に push するたびに自動で公開されます。
`wrangler.toml` に静的ファイル配信と Durable Object（対戦部屋）の設定が入っているので、追加の設定は不要です。

### 2'.（別の方法）GitHub Actions でデプロイ
`.github/workflows/deploy.yml` を同梱しています（初期状態は手動実行のみ）。
1. Cloudflare で API トークン（テンプレート「Edit Cloudflare Workers」）を作成
2. GitHub リポジトリの Settings → Secrets に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を登録
3. Actions タブから「Deploy」を実行（push で自動化したい場合は yml のコメントを外す）

※ 上の Workers Builds と両方使うと二重デプロイになるので、どちらか一方にしてください。

### パソコンで試す
```bash
npm install
npm run dev      # http://localhost:8787 で起動（オンライン対戦も試せます）
```
同じパソコンでタブを2つ開くと、2人対戦の動作確認ができます。

## ファイル構成

```
public/          … 画面（そのまま配信される）
  index.html     … 画面のレイアウト
  style.css      … デザイン
  words.js       … ことばデータベース（ここを編集して語を追加）
  romaji.js      … ローマ字の判定（複数のつづりに対応）
  match.js       … ピッチ・選手・ドリブル・シュートの描画
  sfx.js         … 効果音（WebAudioで生成、音声ファイル不要）
  app.js         … 画面遷移・リーグ・オンライン対戦の処理
src/worker.js    … Cloudflare Worker と対戦部屋（Durable Object + WebSocket）
wrangler.toml    … Cloudflare の設定
```

## しくみメモ
- オンライン対戦は、部屋番号ごとに Durable Object を1つ使い、WebSocket で進み具合を中継します。全員に同じ乱数の種（seed）を配るので、**全員に同じことばが同じ順番で出ます**。
- 1台のパソコンに複数のキーボードをつないでも、ブラウザではどのキーボードか区別できないため、対戦は「1人1台」の方式です。
- 個人情報は扱いません（ニックネームは8文字まで、部屋が空になると状態はリセット）。
